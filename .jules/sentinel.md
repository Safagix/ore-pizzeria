## 2026-05-16 - Subdirectory Config and Template Credential Leak Prevention
**Vulnerability:** A previous commit excluded `js/config.js` in `.gitignore`, but `v2_secured/js/config.js` and `template ore.html` still contained live Firebase API credentials. Because `.gitignore` specified `js/config.js` without a recursive wildcard or leading slash, `v2_secured/js/config.js` was committed into git tracking.
**Learning:** Gitignore patterns without wildcards (such as `js/config.js`) only match paths relative to the root unless written as `**/js/config.js`. Moreover, once a secret-bearing file is added to git index, adding it to `.gitignore` does not retroactively untrack it; it must explicitly be untracked with `git rm --cached`.
**Prevention:** Always use recursive patterns like `**/js/config.js` for configuration files that might exist in subdirectories, sanitize template HTML files with placeholder tokens, and run `git ls-files` to audit what files are actually tracked before committing.
