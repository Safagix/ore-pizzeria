## 2026-05-16 - Hardcoded Firebase Credentials in Multiple Artifacts
**Vulnerability:** Live Firebase credentials (API key, project ID, auth domain, database URL) were leaked in `v2_secured/js/config.js` and `template ore.html`. While `js/config.js` was listed in `.gitignore`, the rule was path-specific rather than recursive (`**/js/config.js`), allowing subdirectory config files to be committed, and older template files still retained sensitive configuration.
**Learning:** Adding ignore rules for top-level directories does not automatically cover submodules, subdirectories (like `v2_secured`), or standalone HTML templates unless recursive patterns are used and static template files are audited. Furthermore, files previously staged or committed must be untracked using `git rm --cached`.
**Prevention:** Use recursive gitignore patterns (`**/js/config.js`), replace credentials in templates with placeholder values, and ensure build scripts (`generate_config.js`) create local configurations dynamically from environment variables rather than persisting credentials in git.
